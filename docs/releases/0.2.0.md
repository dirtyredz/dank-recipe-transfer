# Dank Recipe Transfer 0.2.0 (NeoForge 1.21.1)

First release of the NeoForge line. Same behaviour as the Forge 1.20.1 release 0.1.0, ported to
Minecraft 1.21.1.

- Requires NeoForge 21.1.265 or later 21.1 and Dank Storage 20 for 1.21.1 on both sides; JEI 19.70,
  EMI 1.1.24+1.21.1 and Polymorph 1.2.0+1.21.1 stay optional.
- Ingredients now match on full item components (names, enchantments, custom data), like vanilla
  stacking.
- Works with Dank Storage's auto-sort setting: transfers and rollbacks stay exact when a Dank re-sorts.
- Network protocol 2: a Forge 1.20.1 client or server does not talk to this build; a peer without the
  mod keeps native JEI/EMI behaviour.

Baseline and provenance: branch `neoforge-1.21.1` started at `233d9fdba3cfad061a057c4023bf3571413e789c`
(Forge main); the pack's installed baseline is `v0.1.0` (`881932c83e7d3c28dc67b846cc257a5819f023e9`).
Pinned dependency hashes are in `.ci/port-provenance.json` and the release manifest.

Known limits: Dank Recipe Transfer owns no saved data, so a converted world needs nothing from it;
whether Dank Storage itself carries 1.20.1 storage into 1.21.1 is Dank Storage's conversion, verified
separately by the pack.
